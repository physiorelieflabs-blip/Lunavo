# CineForge Upstream Sources

These are the upstream projects selected for CineForge. No custom model source is introduced here.

| Component | Upstream repository | Role |
|---|---|---|
| Wan 2.2 | https://github.com/Wan-Video/Wan2.2 | Primary video generation |
| KupkaProd Cinema Pipeline | https://github.com/vladimirvalcourt/kupkaprod-cinema-pipeline | Movie orchestration / production workflow |
| HunyuanVideo 1.5 | https://github.com/Tencent-Hunyuan/HunyuanVideo-1.5 | Alternate local video engine |
| LTX-2 | https://github.com/Lightricks/LTX-2 | Alternate synchronized audio/video engine |

## Preservation rule

Keep each upstream project's original license, notices, model terms, and attribution. Do not combine them into a single assumed license.

## Publication model

CineForge is published as an integration project. The GitHub repository does not contain or redistribute model weights.

## Important

GitHub hosts the source repository; the AI inference itself still requires a compatible runtime/GPU environment. GitHub Pages cannot execute these GPU video models.
