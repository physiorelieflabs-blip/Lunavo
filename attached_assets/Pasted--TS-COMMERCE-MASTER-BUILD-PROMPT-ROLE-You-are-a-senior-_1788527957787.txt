# 5. FINANCIAL ACCOUNTING

Never calculate balances by simply modifying:

```text
balance = balance + amount
```

Use a proper immutable financial ledger.

Use:

* integer minor units OR exact decimal arithmetic
* never floating-point arithmetic for money

Every financial event must create ledger entries.

Implement double-entry accounting.

Example:

## Merchant sale

```text
DEBIT  TS_PAY_SETTLEMENT
CREDIT MERCHANT_AVAILABLE
CREDIT TS_COMMERCE_REVENUE
```

The exact accounting entries must be designed consistently according to the transaction type and fee structure.

## Payout reservation

```text
DEBIT  MERCHANT_AVAILABLE
CREDIT MERCHANT_PAYOUTS_PAYABLE
```

## Successful payout

```text
DEBIT  MERCHANT_PAYOUTS_PAYABLE
CREDIT TS_PAY_SETTLEMENT
```

## Failed payout

```text
DEBIT  TS_PAY_SETTLEMENT/PAYOUT_HOLD
CREDIT MERCHANT_PAYOUTS_PAYABLE
DEBIT/CREDIT corresponding reversal entries as required
```

Never silently delete or modify historical ledger entries.

Use reversal/correction entries.
